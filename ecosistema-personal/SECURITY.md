# Política de datos del repositorio

Este proyecto contiene código estático, no datos de progreso. No subir archivos de respaldo, exportaciones JSON, capturas con información personal, credenciales ni copias originales de fuentes que contengan datos embebidos. La exclusión de Git está reforzada en `.gitignore`; revisa los archivos antes de publicar y no confíes solo en esa regla para datos sensibles.

Las apps actuales guardan progreso en el navegador. La futura integración de cuentas debe añadir autenticación y un adaptador de sincronización con control de acceso antes de enviar datos personales a cualquier servicio.
